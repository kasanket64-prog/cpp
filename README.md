# C++ Programming Practice

A collection of **semester-two programming assignments and exercises** covering object-oriented C++ and fundamental language features.

## Topics in this repository

| Topic | Example files |
| --- | --- |
| Classes and constructors | `BasicConstrut.cpp`, `ParaConstrut.cpp` |
| Inheritance | `Inheritance.cpp`, `Inheritance2.cpp` |
| Polymorphism and virtual functions | `Polymorphism.cpp`, `Virtual_Function.cpp` |
| Operator overloading | `Operator_overloading1.cpp`, `Operator_overloading2.cpp`, `Operator_overloading3.cpp` |
| Friend functions | `FriendFn.cpp`, `Friend_Function.cpp` |
| Exceptions and templates | `Exception_handling.cpp`, `class_template.cpp` |

Additional files explore inline and static functions, complex numbers, and small Java/Python arithmetic exercises.

## Run an example

Requires a C++ compiler such as **g++**.

```bash
g++ -std=c++17 Inheritance.cpp -o inheritance-example
./inheritance-example
```

On Windows, execute `inheritance-example.exe` instead. Compile each standalone exercise separately; the files are examples rather than a single application.

## Notes

- Files reflect learning exercises and may use different coding styles.
- Existing compiled executables are not required to read or compile the source.
- This repository is for study and reference, not a production library.
